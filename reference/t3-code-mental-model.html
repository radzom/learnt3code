Begriffe

T3 Code
Die Oberfläche, die Projekte, Threads und Agenten-Sitzungen organisiert.
Provider
Der ausführende Coding-Agent, zum Beispiel Codex.
Projekt
Der Arbeitsordner, dessen Dateien im Auftrag verändert werden können.
Thread
Die fortlaufende Unterhaltung und Arbeitshistorie innerhalb eines Projekts.
Berechtigungsmodus
Legt fest, bei welchen Aktionen der Agent vorher fragen muss.

Sicherheitsregel

Bei unbekannten Projekten oder neuen Arbeitsabläufen mit Supervised beginnen. Mehr Autonomie erst geben, wenn Ziel, Projektgrenzen und Prüfschritte klar sind.

Quelle: offizielle T3-Code-Dokumentation zu Berechtigungsmodi.
