# Mission auf containerisolierte Agenten präzisiert

Der Nutzer will T3 Code für App-Entwicklung, Codeverständnis, Automatisierung und professionelle Workflows einsetzen, aber Agenten konsequent in Docker-Containern ausführen. Der Missionswechsel macht nachweisbare Dateisystem-Isolation – einschließlich negativer Zugriffstests – zur Voraussetzung aller weiteren Architekturentscheidungen; siehe [[MISSION.md]].
