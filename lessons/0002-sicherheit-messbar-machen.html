Sicherheit messbar machen

Dein Gewinn: Aus „der Container sollte isoliert sein“ wird eine Abnahme, die Fehler sichtbar macht.

Konfiguration ist noch kein Beweis

Ein Docker-Compose-Eintrag beschreibt eine Absicht. Eine Prüfung beobachtet Verhalten. Für unseren Workflow brauchen wir deshalb drei Beweisarten:

  1. Positivtest: Erlaubte Entwicklungsarbeit gelingt.
  2. Negativtest: Verbotener Hostzugriff scheitert.
  3. Inspektion: Die laufende Containerkonfiguration entspricht der Allowlist.

Der Host-Canary-Test

Eine Canary-Datei liegt auf dem Host außerhalb des freigegebenen Projekts. Sie enthält einen zufälligen Wert. Der Agent bekommt nur ihren Hostpfad und soll versuchen, sie zu lesen und zu verändern.

# auf dem Host, außerhalb des Projekts
CANARY_FILE=$(mktemp "${TMPDIR:-/tmp}/t3-host-canary.XXXXXX")
openssl rand -hex 24 > "$CANARY_FILE"
shasum -a 256 "$CANARY_FILE"

Bestanden ist der Test nur, wenn der Agent den Inhalt nicht ausgeben kann und der Hash nach dem Versuch unverändert ist. Damit prüfen wir Verhalten statt Vertrauen.

Die laufende Konfiguration prüfen

Prüfe nicht nur die Compose-Datei, sondern den tatsächlich gestarteten Container. Die Ausgabe muss ausschließlich erwartete Mounts zeigen; Privileged muss false sein.

docker inspect t3-agent --format '{{json .Mounts}}'
docker inspect t3-agent --format \
  'privileged={{.HostConfig.Privileged}} readonly={{.HostConfig.ReadonlyRootfs}}'
docker exec t3-agent sh -lc 'id -u; test ! -S /var/run/docker.sock'

Der letzte Befehl ist bestanden, wenn die Benutzer-ID nicht 0 ist und kein Docker-Socket existiert.

Warum T3 mit in die Grenze gehört

Bei T3 Code besitzt der Server Agentenprozesse, Terminal, Git und Dateizugriffe. Für eine klare Containergrenze sollen daher T3-Server und Provider-CLI innerhalb derselben isolierten Umgebung laufen; der Client darf außerhalb bleiben.

Abrufübung

Welcher Test liefert den stärksten Beleg für die gewünschte Dateisystemgrenze?

Deine Entscheidung

Formuliere in einem Satz, welche Hostpfade der Agent lesen oder schreiben darf. „Nur das Projekt“ reicht noch nicht: Benenne auch, wo T3-Zustand, Agent-Anmeldung und temporäre Dateien liegen dürfen.
