Ein Satz, der alles ordnet

T3 Code ist die Steueroberfläche; ein Coding-Agent wie Codex erledigt die Arbeit in deinem Projekt.

Die offizielle Dokumentation beschreibt T3 Code als Web- und Desktop-Oberfläche zum Ausführen lokaler Coding-Agenten. T3 Code bringt diese Agenten nicht selbst mit, sondern steuert deren installierte Kommandozeilenprogramme.

Du→T3 Code→Codex

Codex liest und verändert – abhängig von Auftrag und Berechtigungen – die Dateien des geöffneten Projekts. In diesem Kurs ist das der Ordner learnt3code.

Ein guter Auftrag hat drei Teile

  1. Ziel: Was soll am Ende sichtbar funktionieren?
  2. Grenze: Welche Dateien oder Bereiche gehören dazu?
  3. Prüfung: Woran erkennen wir, dass es korrekt ist?

Beispiel: „Erstelle eine einfache Aufgabenliste in diesem Projekt. Ändere nur die Web-App. Starte die Tests und zeige mir anschließend die geänderten Dateien.“

Sicherheit zuerst

Der Berechtigungsmodus gilt pro Thread. Für unbekannte Projekte ist Supervised ein guter Start, weil Befehle und Dateiänderungen vor der Ausführung bestätigt werden. Full access eignet sich laut Dokumentation eher für isolierte Worktrees oder wegwerfbare Sandboxes.
